# JMcomic for kindle

在 Kindle Paperwhite 5 上看漫画的应用。

装好之后，**打开 KUAL 就能用，不需要连电脑**——服务端跑在 Kindle 自己身上。

> **仅供技术学习与个人使用。** 本项目不附带任何漫画内容，内容来自你自己配置的来源。
> 请遵守当地法律，支持正版。

## 能干什么

| 功能 | 说明 |
|---|---|
| 搜索 | 支持中文拼音输入，不用外接键盘 |
| 历史记录 | 记住看过的本子，点一下就回去 |
| 收藏 | 收藏整本或单话，都存在本地 |
| 作品详情 | 显示**角色**和标签，点一下就能按它搜索 |
| 阅读 | 全屏显示，点屏幕翻页；长条漫自动纵向滚动 |
| 离线缓存 | 看过的页面存在 Kindle 里，再看不用重新下载 |
| 断网可用 | 已缓存的页面即使没网也能看 |

## 准备工作

1. **一台越狱的 Kindle Paperwhite 5**（其他型号没有测过）
2. **系统版本 5.19.2**（本次开发和验证用的版本）
3. **装好 KUAL**（Kindle 的通用应用启动器）
4. **能连 Wi-Fi**
5. **一个可用的漫画来源**——服务端要能访问到它（本项目只提供[接口约定](API-CONTRACT.md)，不含来源）

> 想用电脑当服务端也可以，见[设置项说明](#设置项说明)里的「地址」。

### 怎么查自己的系统版本

Kindle 上：**设置 → 设备选项 → 设备信息**，里面有一行「系统版本」。

5.19.2 的完整版本号长这样：

```
039-juno_1902_malbec_bellatrix-432036
```

> 其他 5.19.x 小版本**理论上也兼容**（本项目只用帧缓冲、evdev、`lipc` 这些老接口），
> 但没有实测过。5.16.x 及更早的版本未测试。

## 安装

### 1. 把文件拷进 Kindle

用 USB 线把 Kindle 连到电脑，它会像 U 盘一样出现（Windows 里通常是 `K:` 盘）。

把压缩包里的 **`kindle-manga` 整个文件夹**放进：

```
Kindle/extensions/
```

放完之后路径必须长这样：

```
Kindle/extensions/kindle-manga/kindle-manga
Kindle/extensions/kindle-manga/kindle-manga-server
Kindle/extensions/kindle-manga/launch.sh
```

> ⚠️ **别拖成两层**（`.../kindle-manga/kindle-manga/kindle-manga`），KUAL 会找不到。

### 2. 弹出设备

在电脑上「安全弹出」，然后拔掉 USB 线。

### 3. 启动

Kindle 上打开 **KUAL** → **JMcomic for kindle** → **Start JMcomic**。

第一次启动大约 5~10 秒：屏幕先显示 `Starting, please wait...`，然后进入历史记录页。

## 怎么用

### 底栏五个图标

屏幕最下面一排，从左到右：

| 图标 | 是什么 |
|---|---|
| 钟表 | **历史记录**——看过的本子，首屏就是它 |
| 放大镜 | **搜索** |
| 房子 | **主页**——关于信息、快速入门 |
| 星星 | **收藏** |
| 齿轮 | **设置** |

当前在哪一屏，那个图标就会变成**黑底白图**。

### 搜索

点底栏的放大镜：

1. 屏幕下半是键盘，直接打字母
2. 键盘上方会出现候选词——**点是中文，不点就是英文**
   - 打 `beijing`，点候选 → 搜「北京」
   - 打 `naruto`，直接按「搜索」→ 搜 `naruto`
3. 想打数字或符号（比如填 IP 地址），点左下角的「**符号**」键切换

搜完之后键盘自动收起，结果显示成**三列封面**，一屏 6 个。
点封面进本子，右下角的小星星可以直接收藏。

### 作品详情页

点开一个本子，上半是封面和名字，下面是两组可点的标签：

```
角色   [森亚露露卡]
标签   [萝莉] [中出] [中文] [全彩] [无修正]
```

**点任意一个都会按它搜索**——想找同一个角色的其他本子，点角色名就行。
标签区最多三行，角色会优先占行（角色多的本子，标签会相应少显示一些）。

> 底栏再点一次「搜索」，能看到**最近搜索**，点一下就能重新搜。

### 看漫画时的操作

**整屏都是画面，没有按钮。** 单击不同位置：

```
┌───────────┬───────────┬───────────┐
│           │           │           │
│           │  （无操作）│           │
│  上一页   │           │   下一页  │
│           │           │           │
│           ├───────────┤           │
│           │   打开菜单 │           │
└───────────┴───────────┴───────────┘
```

- 点**左边三分之一** → 上一页
- 点**右边三分之一** → 下一页
- 点**中下方** → 打开菜单（中间偏上是刻意的死区，免得误触）

菜单里有：

| 项 | 干什么 |
|---|---|
| 上一页 / 下一页 | 和点屏幕一样 |
| 跳转到页 | 输页码直接跳 |
| 章节列表 | 回到本子的目录 |
| 全屏刷新 | 调残影清理的频率（见下） |
| 收藏本话 | 收藏当前这一话 |
| 退出阅读 | 回本子目录 |
| 退出程序 | 完全退出，回到 Kindle 系统 |

**长条漫**（很长的竖图）会变成上下滚动，点上下翻一屏。

### 右下角那个转圈

屏幕右下角有个小圆环在转，代表**正在加载**（下载图片、搜索、打开本子）。
它停下来了就说明加载完了。

- 墨水屏上它是一格一格跳的（不是平滑旋转）—— 平滑动画在这块屏上会拖残影
- 圈很小（约 5mm），不会挡住画面

## 设置项说明

点底栏齿轮进设置：

| 项 | 说明 |
|---|---|
| **地址** | 服务端在哪。**默认空着 = 用 Kindle 内置的服务端**。想用电脑上的服务端，点进去填电脑 IP（如 `192.168.1.5`），端口会自动补 `8001` |
| **连接状态** | 点一下重新检测连接 |
| **全屏刷新** | 墨水屏会留残影，这个数字是「每翻 N 页做一次整屏刷新」。`0` = 关掉，`1` = 每页都刷（最干净但会闪） |
| 翻页热区 | 显示当前点击分区方式 |
| 图片格式 | 服务端发来的图片格式 |
| 候选词每页 | 输入法一屏显示几个候选词 |
| **缓存上限** | 点一下轮换：`512 MB` → `1 GB` → `2 GB` → `不限制`。超出上限会**自动删最久没看的**，不会把 Kindle 塞满 |
| **已用空间** | 显示当前占用，**点一下清空**磁盘缓存 |

### 关于缓存上限

看过的页面会存到 Kindle 里（`Kindle/kindle-manga-cache/`），下次翻开就不用重新下载。

- 默认 **1 GB**，大约能存 3000~4000 页
- 满了之后**自动删最久没看过的章节**，你正在看的不会被动
- Kindle 空间紧张就调小（512 MB），不缺空间就调大或「不限制」

> 改完立刻生效：服务端会马上按新上限清理一次。

### 关于全屏刷新

墨水屏看漫画会攒残影（前几页的浅影叠在画面上）。全屏刷新是整屏闪一下黑再白，把残影清干净。

- 觉得残影明显 → 调小这个数字（比如 `3`）
- 觉得闪得烦 → 调大（比如 `10`），或设 `0` 关掉

默认值会存在 `extensions/kindle-manga/refresh.txt`。

## 常见问题

### 启动后显示「无法连接服务器」

默认用 Kindle 内置的服务端，正常情况下不会出现这个。

如果出现了：

1. 确认 Kindle 连着 Wi-Fi（内置服务端要联网才能下载图片）
2. 点「重试」
3. 还不行 → 进设置，把「地址」**清空**保存，让它回到内置服务端

### 页面加载很慢

第一次看某一页要从网上下载，慢是正常的，之后会缓存到本地。

- 看过的页面再翻开应该是**秒开**
- 如果一直很慢，可能是网络问题，或者来源站本身慢

### 图有点糊

漫画页会缩放到屏幕尺寸显示。切换「竖边适应 / 横边适应」试试：

阅读器 → 中下方打开菜单 → 有的版本这里能切（长条漫不显示这一项）。

### 翻页卡顿、按键没反应

先看日志（见下）里有没有「缩放偏慢」的警告。有的话说明这一页特别大。

### 想看日志

两种方式：

1. **KUAL 里**：JMcomic for kindle → **Show recent log**，直接把最后 30 行打到屏幕上
2. **USB 连电脑**：日志在 `Kindle/kindle-manga-logs/`，每次运行一个文件

服务端自己的日志也在同一个目录，文件名是 `server-<时间>.log`。

出问题时**先拍照/拷日志**，比描述症状有用得多。

### 缓存占太多空间

两个办法：

1. 设置 → **「缓存上限」** 调小（比如 512 MB），改完立刻清理
2. 设置 → **「已用空间」** 点一下，直接清空

缓存目录是 `Kindle/kindle-manga-cache/`，单页约 200~350 KB。

### 屏幕卡住 / 退不出去

- 阅读器菜单里有「退出程序」
- 出错页右上角有电源键图标，点了也能退出
- 实在不行长按电源键 20 秒强制重启

## 卸载

1. 删除 `Kindle/extensions/kindle-manga/` 整个文件夹
2. （可选）删除 `Kindle/kindle-manga-cache/` 和 `Kindle/kindle-manga-logs/`

你的收藏和历史记录都在扩展目录里（`favorites.json` / `history.json`），删之前想留着就先拷出来。

## KUAL 菜单里的另外两项

| 菜单 | 用途 |
|---|---|
| **Show recent log** | 显示最近一次运行的日志。出问题先看这个 |
| **Self-test (writes to USB)** | 环境自检，写一份诊断到 `Kindle/kual-selftest.txt`。不启动应用，零风险 |
