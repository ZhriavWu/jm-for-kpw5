# JMcomic for kindle · UI 规格书 v6

> 本文是界面重做的**唯一权威规格**。所有数值取自 1:1 真机稿
> `design/ui-preview.html`（浏览器打开可看效果，共 17 屏）。
> 单位一律 **Kindle Paperwhite 5 物理像素**（1236 × 1648），可直接写进代码。

- 目标设备：Kindle Paperwhite 5，屏幕 **1236 × 1648**，16 级灰阶
- 渲染方式：Rust + Slint，framebuffer 直写（`slint-backend-kindle`，已 vendor）
- 字体：文泉驿微米黑（无衬线），固定，**不可换**
- 状态：**规格已冻结**。未决项集中在第 10 节，其余照本实现。

**版本沿革**

| 版本 | 改了什么 |
|---|---|
| v5 | 删掉中/英模式键；输入框内容 = 最终搜索词；主页极简化；快速入门；菜单改覆盖式；星标两态 |
| **v6** | **候选词栏照 Kindle 系统输入法重做：横排一行 + 两端尖角翻页键**（108 + 204×5 + 108 = 1236）。其余一律沿用 v5 |

## 1. 硬约束（违反即返工）

这九条不是建议，是这块屏的物理事实。设计稿里每一条都遵守了，实现时也不能破。

| # | 约束 | 原因 |
|---|---|---|
| 1 | **只有 16 级灰，且 238–255 之间是空的** | 灰阶只有 0–15 档，浅灰做不出来；两个不同值的浅灰会渲染成色带 |
| 2 | **没有颜色** | 分区只靠三样：反白（黑底白字）、边框粗细、留白 |
| 3 | **没有动效、没有 hover、没有过渡** | 刷新一次 1–3 秒。任何"动画"都会留下一串残影 |
| 4 | **边框最细 2px，主线 3px** | 1px 的线在墨水屏上会被吃成断线，看起来像没画 |
| 5 | **没有滚动，全部翻页** | 列表一律整屏分页 + 底部翻页条。禁止设计滑动手势 |
| 6 | **触摸只有单击** | 没有长按、没有滑动、没有双击。可点区域 ≥ 100px |
| 7 | **不用符号字形** | `✕ ▶ ⌫ ★` 这类字符在文泉驿微米黑里会缺字、掉成空白。图标一律 SVG |
| 8 | **不用 #F5F5F5 之类的浅灰底** | 和背景糊在一起。分层改「黑框 + 纯白」 |
| 9 | **覆盖优于重排** | 弹层盖在内容上，底下内容一个像素都不动。布局重排 = 整屏刷新 = 闪 |

### 1.1 由第 3、9 条派生的两条实现纪律

- **高度恒定**：候选词栏永远 142px、结果区永远同高。状态切换时**不重排**，只重画变化的那块。
- **覆盖式弹层**：阅读器菜单是**画在图片上层**的，图片本身**不重新缩放、不重算**。关闭菜单时把被盖住的那块从图片缓冲贴回即可。

## 2. 设计令牌

### 2.1 灰阶（全稿只用这六档，出现第七档即为 bug）

```
--ink:   #000000   主文字、边框、反白底       灰阶 0
--g5:    #555555   次级文字（说明、当前值）   灰阶 5
--g8:    #888888   分隔线                    灰阶 8
--g9:    #999999   禁用态                    灰阶 9
--g12:   #cccccc   占位框、不可见图示         灰阶 12
--paper: #ffffff   背景、卡片                灰阶 15
```

> **禁用态是全稿唯一的灰化表达**（如第一页的「上一页」）。除此之外任何地方都不许用灰色表示"不可点"。

### 2.2 描边

| 弹层顶部边界 | `3px` |
| 热区示意（**仅设计稿**，真机不画） | `2px` 虚线 |

### 2.3 字号

### 2.4 图标

统一 **`viewBox="0 0 100 100"`，`stroke-width="7"`**，`fill:none`，`stroke:currentColor`，`stroke-linecap:square`。

> 缩到 66px 后实际笔画约 **4.6px**，和文字笔画同一量级 —— 这是保证图标"不显得像没画"的关键。**不要为了精致把描边调细。**

| 菜单行内（星标） | `46px` | 9（缩后 ~4.1px） |

#### 候选词栏（v6 · 照 Kindle 系统输入法）

```mermaid
flowchart LR
  L["尖角 108×142"] --> A["候选 204×142"] --> B["候选"] --> C["候选"] --> D["候选"] --> E["候选 204×142"] --> R["尖角 108×142"]
```

```
整条      142px = 上 3px 黑线 + 136px 内容 + 下 3px 黑线
左右翻页键 108 × 142px，各一个
          内含尖角 SVG 56 × 56px，stroke-width 10（缩到实机约 5.6px）
候选格     204 × 142px，一屏 5 个
格间       2px #888 竖线（首尾格不与翻页键共用竖线）
字号       44px；5 字及以上自动降到 36px
点中态     整格反白 #000 底 + #fff 字
空状态     显示说明文字 29px #555 居中，**整条高度不变**
键盘       去掉上边框（由候选词栏的下边框兼任）
```

**宽度核算**：`108 + 204 × 5 + 108 = 1236` —— 正好铺满屏宽，一格不剩、一格不挤。

**翻页键两态**（全稿唯一在此处出现的灰化表达）：

| 状态 | 颜色 | 含义 |
|---|---|---|
| 到头了 | `#999` | 已在第一页或最后一页，没得翻，点了没反应 |
| 还能翻 | `#000` | 后面还有候选词，点一下换下一批 |

> **尖角必须用 SVG 画，不要用 `<` `>` 两个字符。** 理由两条：①这两个字形在大字号下又细又长，和 44px 的汉字笔画不匹配；②字体缺字会直接掉成空白（同硬约束第 7 条）。
>
> **不做页码、不做小圆点。** 墨水屏上那些东西看不清，翻页键的灰/黑就是唯一的状态提示。

> `5` = 每页候选数，对应代码里的 `ime::PAGE`，与 `ui/app.slint` 里的常量必须同步。
> 注意：拼音表每页原本是 12 个，v6 改成 5 个后，`ime::PAGE` 需要一并调整，或由 UI 层对 12 个结果再分 3 页显示。

**键盘**（`466px`，上下 padding 12px，左右 60px）：

```
每行高 100px，行间 gap 14px（4 行 = 4×100 + 3×14 = 442 + 24 padding = 466 ✓）
字母键   100 × 100px，3px 边框，40px 字
功能键   字号 30px

行1  q w e r t y u i o p
行2  a s d f g h j k l
行3  z x c v b n m | 删除(168px)
行4  符号(168) 空格(320) 搜索(256,反白) 收起(168)
```

> **第 4 行 v5 改动**：原「中 / 英」模式键的两个键帽**已删除**，宽度分配给其余键。

**输入法行为规格**（照 Kindle 系统输入法）：

```
1. 用户敲字母 → 输入框显示字母原文（此时"是英文"）
2. 候选栏出汉字（拼音表查询 + 分词回退）
3. 用户点候选词 → 输入框里的字母被整体替换成该汉字词
4. 用户不点候选，直接按「搜索」→ 按输入框里的原文搜索
5. 按「删除」键 → 已选中的汉字词**整体一次删掉**，退回成字母原文
   （不是逐个删汉字，避免误选后重打）
6. 点另一个候选词 → 直接替换，无需先删
7. 混输支持：选完汉字后可继续打空格 + 字母，继续出候选
8. 字母切不出合法音节时（如 sakura）→ 候选区显示说明文字，直接搜原文
```

#### 三个状态（对应设计稿 ②③④ 屏）

| 状态 | 输入框 | 候选词栏 | 点搜索 |
|---|---|---|---|
| 打完字母未选字 | `yuan shen` | 5 个汉字候选，左键灰、右键黑 | 搜 `"yuan shen"` |
| 已选候选 | `原神` | 5 个候选 | 搜 `原神` |
| 非拼音输入 | `sakura` | 空（只有说明文字），两个键都灰 | 搜 `sakura` |

**第 1 页「先让它跑起来」**

1. 在电脑上启动服务端 `[必须先做]` — 命令框 `python jm_kindle_raw.py`；提示「出现 Listening ... 8001 就说明起来了，别关这个窗口」
2. 确认 Kindle 和电脑在同一个 Wi-Fi — 附查 IP 方法（Win+R → cmd → ipconfig）
3. 回首页，看最上面那条黑条 — 已连接 / 未连接两种情况的处理

**第 2 页「怎么看漫画」**

4. 找漫画 — 敲字母 → 想搜中文就点候选词，不想就按「搜索」；或点钟表看历史
5. 挑一话开始看 — 点作品 → 章节列表 → 点某一话
6. 阅读器里怎么操作 — **把热区直接写进说明书**（左/右/中下）
7. 觉得残影重怎么办 — 菜单 → 全屏刷新 → 每 5 页；并说明翻页要等 1–3 秒、会闪，不是卡住

## 6. 文案规范

- **全部中文，不用符号字形。** 「返回」「上一页」「下一页」「删除」「收起」「知道了」—— 不用 `← → ✕ ⌫`

- 出错信息必须包含**可操作的具体步骤**（跑哪个脚本、查什么），不能只说"失败"
- 阅读器的操作说明要写进**快速入门第 6 步**，不要只放在一次性提示里
